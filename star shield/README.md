# Star Shield 2.0

Космическая аркада на Python + PyGame: волны врагов, боссы, бонусы, комбо, бомбы,
достижения, таблица рекордов, два языка, поддержка геймпада.

## Запуск

```
pip install -r requirements.txt
python main.py
```

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Движение | стрелки / A, D | левый стик / крестовина |
| Стрельба | ПРОБЕЛ | кнопка A |
| Бомба | B или X | кнопка X |
| Пауза | P или ESC | Start |
| Полный экран | F11 | |

## Что в игре

- Модели нарисованы кодом: истребитель с анимированным пламенем двигателей, четыре вида пришельцев с анимацией (красный дрон, фиолетовая оса, оранжевый жук, голубой глаз-стрелок) и босс - корабль-матка с огромным глазом
- Светящиеся пули и бонусы, щит-пузырь, вспышка при попадании
- Босс каждые 5 уровней, во второй половине здоровья он звереет
- Бонусы: щит, скорострельность, жизнь, улучшение оружия (до 3 уровня), бомба
- Комбо-множитель до x5, эффекты взрывов, тряска экрана
- 10 достижений, таблица рекордов (топ-10), статистика
- 3 уровня сложности, русский и английский язык
- Звуки и музыка создаются программно; свои файлы можно положить в `assets/audio/`
  (`menu_music.ogg`, `game_music.ogg`)
- Свой шрифт: `assets/fonts/game_font.ttf` (рекомендуется для выпуска, см. STEAM_CHECKLIST.md)
- Сохранения и настройки лежат в папке пользователя (`%APPDATA%/StarShield` на Windows)

## Структура проекта

- `main.py` - класс `App`: окно, фон, экраны, цикл, отчёт о сбоях
- `screens/` - экраны: `menu`, `game`, `settings`, `help`, `scores`, `achievements`, `credits`
- `systems/config.py` - константы, пути, настройки (JSON)
- `systems/state.py` - сохранение: рекорды, статистика, достижения
- `systems/entities.py` - `Player`, `Bullet`, `Enemy`, `Boss`, `Bonus`, `Star`
- `systems/effects.py` - частицы и всплывающий текст
- `systems/sprites.py` - вся графика: модели кораблей, пришельцев, босса, бонусов, пуль
- `systems/audio.py` - программный звук и музыка
- `systems/controls.py` - клавиатура и геймпад
- `systems/i18n.py` - переводы
- `systems/achievements.py`, `systems/steam.py` - достижения и необязательная связь со Steam
- `build.py` - сборка приложения (PyInstaller)
- `STEAM_CHECKLIST.md` - что ещё нужно для выпуска в Steam
- `docs/zashita_star_shield_v2.md` - материал для защиты курсовой
